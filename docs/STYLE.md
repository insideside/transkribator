# «Стенограмма» — дизайн-система

Мягкая редакционная эстетика для локальных веб-приложений: приглушённый **стол**, на нём приподнятый **лист**,
бумага и чернила вместо «продуктового» UI, один тёплый акцент. Две темы (тёмная — по умолчанию) и режим «как в системе».

Живая демонстрация всех компонентов: [`app/static/style-guide.html`](../app/static/style-guide.html)
(в запущенном приложении — http://127.0.0.1:8770/style-guide.html).

---

## Подключение в другой проект

Скопируйте два файла из `app/static/`:

| Файл | Что это |
|---|---|
| `stenogramma.css` | токены обеих тем, основа страницы, типографика, поверхности и компоненты |
| `theme.js` | тема `auto / dark / light`: применяет её до отрисовки, запоминает выбор, в режиме «Авто» следит за системной темой |

```html
<!doctype html>
<html lang="ru" data-default-theme="dark">        <!-- тема по умолчанию: dark | light | auto -->
<head>
  <meta charset="utf-8">
  <script src="theme.js"></script>                <!-- обычный <script> в <head>, без defer — иначе мигнёт не та тема -->
  <link rel="stylesheet" href="stenogramma.css">
  <style>/* стили самого приложения — только через токены */</style>
</head>
<body>
  <main style="position:relative; z-index:1">     <!-- контент поверх «зерна» стола -->
    <div class="sheet"> … </div>
  </main>
</body>
</html>
```

Никаких сборщиков, фреймворков и внешних шрифтов: всё работает офлайн.

## Принципы

1. **Не «очередной ИИ-продукт».** Никаких фиолетовых градиентов, крупных скруглённых карточек-плиток и системного шрифта по умолчанию.
   Характер задают антиква, бумажные тона и типографские детали: капитель, моноширинные цифры, тонкие линейки.
2. **Мягкий контраст.** Основной текст не белый на чёрном, а тёплый бежевый на графите (`--ink` на `--sheet`).
   Чистые #000 и #fff не используются.
3. **Глубина из трёх уровней, а не плоскость:**
   - **стол** (`--desk`) — фон страницы с мягким пятном света и зерном;
   - **лист** (`.sheet`) — основной документ, приподнят тенью;
   - **на листе** — выпуклое (`.raised`, кнопки, выбор из списка, плеер, «таблетки») и утопленное (`.inset`, поля ввода, жёлоб прогресса, зона перетаскивания).
   Правило: **то, что нажимают, — выпуклое; то, куда вводят или что заполняется, — утопленное.**
4. **Один акцент** (`--accent`, терракота). Он для главного действия, активного состояния и прогресса — не для декора.
   Больше одной кнопки `.btn.solid` на экране не нужно.
5. **Капитель для служебных подписей** (`.smallcaps`), **моно — для чисел и времени** (`.mono`), **курсив — для пояснений** (`.note`, `.lede`).

## Токены

Все цвета задаются только через переменные: тогда обе темы работают автоматически.

| Токен | Назначение | Тёмная | Светлая |
|---|---|---|---|
| `--desk`, `--desk-glow` | фон страницы и пятно света | `#141311`, `#2a2620` | `#e4ddcf`, `#f1ebe0` |
| `--sheet` | лист | `#1f1d19` | `#f6f2ea` |
| `--sheet-2` | выпуклые элементы на листе | `#26231e` | `#efe9de` |
| `--sunken` | утопленные области | `#181714` | `#ebe5d8` |
| `--ink-strong` | заголовки | `#e9e1d0` | `#26221c` |
| `--ink` | основной текст | `#d2c9b6` | `#3a342c` |
| `--ink-2` | второстепенный текст | `#a39a88` | `#625a4d` |
| `--ink-3` | подписи, плейсхолдеры | `#756d60` | `#928878` |
| `--rule`, `--rule-2` | линейки и рамки (полупрозрачные) | 8 % / 15 % от `--ink` | 9 % / 17 % |
| `--accent`, `--accent-2` | акцент и его тёмный край (градиент) | `#d4705a`, `#b9573f` | `#b5533d`, `#9c4230` |
| `--accent-soft` | фон подсветки акцентом | 12 % | 9 % |
| `--on-accent` | текст на акценте | `#fff7ee` | `#fff7ee` |
| `--hl` | наведение / подсветка строки | 5 % | 4 % |
| `--c1` … `--c8` | 8 различимых «чернил» для категорий (говорящие, теги) | пастельные | насыщенные |
| `--shadow-sheet` / `--shadow-raised` / `--shadow-inset` | тени трёх уровней глубины | | |

Прочее: `--serif`, `--serif-display`, `--sans`, `--mono` — шрифты; `--measure: 52rem` — ширина листа; `--r: 10px`, `--r-sm: 6px` — радиусы.

### Шрифты

| Роль | Семейство | Запасные |
|---|---|---|
| текст | PT Serif | Charter, Georgia |
| заголовки | PT Serif Caption | PT Serif, Georgia |
| служебные подписи, кнопки | PT Sans (капитель, `letter-spacing .08–.14em`) | Avenir Next, Segoe UI |
| числа, время | PT Mono | Menlo, Consolas |

PT-шрифты встроены в macOS. Для Windows/Linux их можно бесплатно скачать у ParaType (лицензия OFL).
Без них срабатывают запасные — вид остаётся приличным.

## Компоненты

### Поверхности
```html
<div class="sheet">лист — основной документ</div>
<div class="raised">выпуклая плашка на листе</div>
<div class="inset">утопленная область</div>
<hr class="rule">
```

### Типографика
```html
<div class="kicker smallcaps">Надзаголовок</div>
<h1>Заголовок</h1>
<p class="lede">Вводный абзац курсивом.</p>
<p class="note">Пояснение.</p>
<span class="mono">00:12:45</span>
```

### Кнопки
```html
<button class="btn solid">Главное действие <span class="arrow">→</span></button>
<button class="btn">Обычная</button>
<button class="btn quiet">Тихая</button>
<button class="btn danger">Удалить</button>
```
Кнопки не переносят текст (`nowrap`), а при нехватке места обрезают его многоточием. Можно использовать и как `<a class="btn">`.

### Поля
```html
<label class="field"><span class="smallcaps">Язык</span>
  <select class="control"><option>Русский</option></select>
</label>
<input class="control" placeholder="Найти…">
<label class="chk"><input type="checkbox" checked>таймкоды</label>
```

### «Таблетка», прогресс, сообщения
```html
<span class="chip" style="color: var(--c2)">Спикер 2</span>    <!-- .chip.dim — второстепенная -->
<div class="groove"><div class="fill" style="width: 40%"></div></div>
<div class="notice">Предупреждение</div>
<div class="toast show">Текст скопирован</div>                  <!-- класс .show — показать -->
```

### Модальное окно
```html
<div class="modal-backdrop" id="dlg" hidden>
  <div class="modal" role="dialog" aria-modal="true" aria-labelledby="dlgTitle">
    <div class="modal-head"><div class="kicker smallcaps">Раздел</div><h2 id="dlgTitle">Заголовок</h2></div>
    <div class="modal-body">Содержимое прокручивается, если не помещается.</div>
    <div class="modal-foot"><button class="btn quiet">Отмена</button><button class="btn solid">Действие</button></div>
  </div>
</div>
```
Показывается и скрывается атрибутом `hidden`. Закрытие по Esc и по клику на фон реализует страница
(в Транскрибаторе — окно обновлений). Точка-метка на кнопке: `<button class="btn">Обновления<span class="dot"></span></button>`.

### Переключатель темы
```html
<div class="theme-switch" role="group" aria-label="Тема">
  <button data-theme-set="auto">Авто</button>
  <button data-theme-set="dark">☾</button>
  <button data-theme-set="light">☀</button>
</div>
```
Активная кнопка подсвечивается только средствами CSS (по атрибуту `data-theme-pref` на `<html>`), обработчики писать не нужно.
Из кода: `stTheme.get()`, `stTheme.set("light")`, событие `document` → `themechange`.

## Раскладка (как в Транскрибаторе)

- Шапка: название капителью с точкой-акцентом, справа переключатель темы и главное действие.
- Слева узкая колонка-«журнал» (≈290 px) прямо на столе; выбранный пункт приподнят (`--sheet` + `--shadow-raised`).
- Лист шириной `--measure` **центрируется по экрану, а не по колонке**:
  `margin-left: max(0px, min(calc(50vw - <ширина левой колонки с отступами> - var(--measure)/2), calc(100% - var(--measure))))`.
- На ширине < 900 px — одна колонка, лист на всю ширину, отступы 16–18 px.

## Проверка перед выпуском

1. Обе темы и режим «Авто» (переключите системную тему — страница должна поменяться сама).
2. Ширина 360 / 420 / 900 / 1300 / 1600 px — ничего не вылезает за кнопки и блоки, нет горизонтальной прокрутки.
   Удобно проверять в iframe нужной ширины: для каждого элемента сравнить `scrollWidth` и `clientWidth`
   и убедиться, что `getBoundingClientRect()` не выходит за ширину окна.
3. Длинные строки (название, имя) обрезаются многоточием, а не ломают вёрстку: `min-width: 0` у элементов flex/grid,
   `text-overflow: ellipsis` у однострочных.
4. Фокус с клавиатуры виден (`:focus-visible`: кольцо цвета акцента).
