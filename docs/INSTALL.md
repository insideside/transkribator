# Установка Транскрибатора

Пошаговая инструкция для macOS и Windows. Поставить приложение можно через git или из ZIP-архива.
Требования к компьютеру описаны в [REQUIREMENTS.md](REQUIREMENTS.md).

- [Перед началом](#перед-началом)
- [Через git](#через-git): [macOS](#macos-git), [Windows](#windows-git)
- [Через ZIP-архив](#через-zip-архив): [macOS](#macos-zip), [Windows](#windows-zip)
- [Что делает установщик](#что-делает-установщик), [первый запуск](#первый-запуск), [параметры установщика](#параметры-установщика)
- [Обновление](#обновление), [переход с ZIP на git](#переход-с-zip-на-git), [удаление](#удаление), [если что-то пошло не так](#если-что-то-пошло-не-так)

## Перед началом

### Git или ZIP

| | Через git | Через ZIP |
|---|---|---|
| Обновление | кнопкой «Обновления» в приложении | вручную, новым архивом |
| Что нужно заранее | программа git | ничего |
| Что делать | несколько команд в терминале | скачать и распаковать архив, потом одна команда (macOS) или двойной щелчок (Windows) |

Git удобнее тем, что его ставят один раз, а дальше обновления приходят кнопкой.

### Куда положить папку

Приложение запускается из своей папки, там же хранятся модели (3-5 ГБ), журнал и записи.

- macOS: домашняя папка, то есть `/Users/<имя>/transkribator`. В Finder её открывает меню «Переход > Домой» или ⇧⌘H.
- Windows: `C:\Users\<имя>\transkribator`.

Не стоит класть приложение в «Документы» или на «Рабочий стол», если они синхронизируются с iCloud Drive или OneDrive
(Windows часто включает это сама). Тогда в облако начнут выгружаться гигабайты моделей и ваши записи. «Загрузки»,
внешний диск и флешка тоже не подходят, нужна постоянная папка на компьютере.

### Интернет

Интернет нужен только на время установки, скачивается 2-5 ГБ. Потом приложение работает без сети.

## Через git

### macOS (git)

1. Откройте Терминал: Spotlight (⌘ Пробел), затем «Терминал». Он же лежит в «Программы > Утилиты».
2. Перейдите в домашнюю папку и скачайте приложение:
   ```bash
   cd ~
   git clone https://github.com/insideside/transkribator.git
   ```
   Если git ещё не установлен, macOS предложит поставить инструменты разработчика. Нажмите «Установить»,
   подождите несколько минут и выполните `git clone` ещё раз.
3. Запустите установщик:
   ```bash
   cd ~/transkribator
   bash install.sh
   ```
4. Дождитесь надписи «Готово!». Это занимает 5-20 минут, больше всего времени уходит на скачивание моделей.
   Если у вас стоит [Übersicht](https://tracesof.net/uebersicht/), установщик спросит, поставить ли виджет на рабочий стол.
5. Дальше смотрите [первый запуск](#первый-запуск).

### Windows (git)

1. Поставьте git, если его ещё нет. Откройте Терминал (правый клик по кнопке «Пуск», пункт «Терминал»;
   в Windows 10 он называется «Windows PowerShell») и выполните:
   ```powershell
   winget install --id Git.Git -e
   ```
   Можно и вручную: скачать установщик с [git-scm.com/download/win](https://git-scm.com/download/win) и пройти его
   с настройками по умолчанию. После установки закройте Терминал и откройте заново, иначе команда `git` не найдётся.
2. Скачайте приложение в свою папку:
   ```powershell
   cd ~
   git clone https://github.com/insideside/transkribator.git
   ```
3. Запустите установщик:
   ```powershell
   cd transkribator
   .\install.bat
   ```
   Можно и мышью: открыть папку `C:\Users\<имя>\transkribator` и дважды щёлкнуть `install.bat`.
4. Дождитесь надписи «Готово!» и нажмите любую клавишу, окно закроется.
5. Дальше смотрите [первый запуск](#первый-запуск).

## Через ZIP-архив

Архив скачивается со страницы [github.com/insideside/transkribator](https://github.com/insideside/transkribator):
зелёная кнопка Code, пункт Download ZIP. Внутри лежит папка `transkribator-main`.

### macOS (ZIP)

1. Safari сам распакует архив в «Загрузки», и там появится папка `transkribator-main`. Если этого не произошло,
   дважды щёлкните `transkribator-main.zip`.
2. Перенесите папку `transkribator-main` в домашнюю папку (⇧⌘H в Finder). Её можно переименовать в `transkribator`,
   на работу это не влияет.
3. Откройте Терминал и выполните (если переименовали папку, поправьте имя):
   ```bash
   cd ~/transkribator-main
   bash install.sh
   ```
   Запускать нужно так, через Терминал. Двойной щелчок по `install.sh` не сработает: macOS не открывает скрипты
   из интернета и пишет, что не удаётся проверить разработчика. Установщик сам снимает эту метку с файлов приложения.
4. Дождитесь надписи «Готово!», дальше смотрите [первый запуск](#первый-запуск).

### Windows (ZIP)

1. Найдите скачанный `transkribator-main.zip` в «Загрузках».
2. Разблокируйте архив, иначе Windows будет показывать предупреждение при каждом запуске: правый клик по архиву,
   «Свойства», внизу галочка «Разблокировать», «ОК». Если такой галочки нет, этот шаг можно пропустить.
3. Распакуйте архив: правый клик, «Извлечь все...», в поле пути укажите `C:\Users\<имя>` и нажмите «Извлечь».
   Появится папка `C:\Users\<имя>\transkribator-main`. Проводник открывает ZIP как обычную папку, но изнутри архива
   установка не сработает, сначала его нужно распаковать.
4. Откройте папку `transkribator-main` и дважды щёлкните `install.bat`. Если появится синее окно «Система Windows
   защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».
5. Дождитесь надписи «Готово!», нажмите любую клавишу и переходите к [первому запуску](#первый-запуск).

## Что делает установщик

Всё ставится в папку приложения и в вашу домашнюю папку. Права администратора не нужны, системный Python
и другие программы установщик не трогает.

| Шаг | Что происходит | Сколько времени |
|---|---|---|
| 1/4 | Ставит [uv](https://docs.astral.sh/uv/), менеджер Python-окружения, в `~/.local/bin` | секунды |
| 2/4 | uv скачивает Python 3.12 и библиотеки строго по списку версий из `uv.lock`. На Windows с видеокартой NVIDIA ещё и библиотеки CUDA, около 1,3 ГБ | 1-5 мин |
| 3/4 | Скачивает модели: для разделения по голосам (около 80 МБ) и для распознавания. Если есть видеокарта, ставится точная модель (3 ГБ), если нет, быстрая (1,6 ГБ) | 1-15 мин |
| | Самопроверка: ffmpeg, движок распознавания, модели и прогон тестового звука через всю обработку | около 30 с |
| 4/4 | Ярлык: на Mac «Транскрибатор» в «Программах», на Windows на рабочем столе и в меню «Пуск» | секунды |

Если всё прошло хорошо, самопроверка выглядит так:
```
Проверка установки (движок: mlx, Python 3.12, darwin)
  ✓ ffmpeg: ffmpeg читает m4a
  ✓ Движок распознавания: MLX, Device(gpu, 0)
  ✓ Модели диаризации: есть
  ✓ Диаризация: sherpa-onnx загружает модели
  ✓ Весь конвейер: модель large-v3, конвейер отработал
  ✓ Запись звука компьютера: системный звук macOS (все приложения)
Всё работает.
```
Если в какой-то строке стоит ✗, смотрите раздел [если что-то пошло не так](#если-что-то-пошло-не-так).
Установщик можно запускать повторно, уже скачанное он не качает заново.

## Первый запуск

На Mac приложение «Транскрибатор» лежит в «Программах», его можно найти через Launchpad или Spotlight. Пока оно
работает, значок виден в Dock. Остановить приложение можно правым кликом по значку и пунктом «Завершить». Чтобы
закрепить значок, выберите в том же меню «Параметры > Оставить в Dock». Запасной вариант запуска: двойной щелчок
по `start.command` в папке приложения.

На Windows приложение запускается ярлыком «Транскрибатор» на рабочем столе или в меню «Пуск». На панели задач
появится свёрнутое окно «Transkribator», это сервер. Закройте его, когда захотите остановить приложение.
Запасной вариант запуска: `start.bat` в папке приложения.

В обоих случаях откроется браузер с адресом http://127.0.0.1:8770. Его можно добавить в закладки, он работает, пока
приложение запущено. Страница открывается с вашего же компьютера, в интернет ничего не уходит.

Про запись звука компьютера («Слушать»). На Mac при первой записи macOS спросит, можно ли приложению
«Транскрибатор Звук» записывать системный звук. Нажмите «Разрешить». Микрофон при этом не используется, пишется
только звук, который играет компьютер. Если случайно отказали, разрешение включается в Системных настройках:
Конфиденциальность и безопасность > Запись экрана и системного звука. На Windows разрешение не нужно.

## Параметры установщика

На Mac параметры пишутся после `bash install.sh`, на Windows после `.\install.bat` (в Терминале, из папки приложения).

| macOS / Linux | Windows | Что делает |
|---|---|---|
| `--all-models` | `-AllModels` | скачать обе модели, точную (3 ГБ) и быструю (1,6 ГБ), чтобы выбирать при загрузке |
| `--model large-v3` | `-Model large-v3` | скачать конкретную модель: `large-v3` точная, `large-v3-turbo` быстрая |
| | `-Cpu` | не использовать видеокарту NVIDIA, если с ней проблемы |
| `--no-shortcut` | `-NoShortcut` | не создавать ярлыки |
| `--no-widget` | | не предлагать виджет Übersicht |

Вторую модель можно докачать позже, запустив установщик ещё раз с `--all-models` или `-AllModels`.

## Обновление

Если приложение ставили через git, нажмите «Обновления» в шапке. Точка на кнопке значит, что вышла новая версия.
В окне видно, что изменилось. После нажатия «Обновить» приложение само скачает изменения, при необходимости
доустановит библиотеки и перезапустится. Модели, журнал и записи не пострадают. Вручную то же самое делается так:
`cd ~/transkribator && git pull`, затем установщик ещё раз.

Если приложение ставили из ZIP, скачайте новый архив и распакуйте его поверх старой папки. На Windows это «Извлечь
все...» в ту же `C:\Users\<имя>`, а на вопрос о замене файлов ответ «Заменить». На Mac скопируйте содержимое новой
`transkribator-main` в старую с заменой. Потом запустите установщик: он доставит изменения, модели и журнал
останутся. Можно один раз [перейти на git](#переход-с-zip-на-git), тогда обновлять станет проще.

## Переход с ZIP на git

Так включаются обновления кнопкой, а модели не приходится скачивать заново.

1. Поставьте git (смотрите первый шаг для [macOS](#macos-git) или [Windows](#windows-git)) и выполните `git clone`
   в домашней папке. Появится новая папка `transkribator`.
2. Перенесите из старой папки `transkribator-main` в новую папки `models` и `data`, а также файл `settings.env`,
   если он есть. Так сохранятся модели, журнал и записи.
3. Запустите установщик в новой папке. Это займёт около минуты, потому что модели уже на месте. Ярлыки
   перенастроятся на новую папку.
4. Старую папку `transkribator-main` удалите.

## Удаление

1. Запустите `uninstall.sh` (на Mac: `bash ~/transkribator/uninstall.sh`) или `uninstall.bat` на Windows.
   Они удалят ярлыки, приложение из «Программ» и виджет.
2. Удалите папку приложения. Вместе с ней удалятся модели, журнал и загруженные записи.
3. Если менеджер uv больше ничем не используется, его тоже можно удалить вместе с кэшем:
   - macOS: `uv cache clean && rm -rf "$(uv python dir)" && rm ~/.local/bin/uv ~/.local/bin/uvx`
   - Windows (Терминал): `uv cache clean; Remove-Item -Recurse -Force "$(uv python dir)"; Remove-Item $HOME\.local\bin\uv.exe, $HOME\.local\bin\uvx.exe, $HOME\.local\bin\uvw.exe`

Больше приложение ничего в системе не оставляет.

## Если что-то пошло не так

Сначала запустите самопроверку в папке приложения: `.venv/bin/python -m app.selftest` на Mac
или `.venv\Scripts\python.exe -m app.selftest` на Windows. Подробности ошибок пишутся в `data/logs/app.log`.

| Что происходит | Что сделать |
|---|---|
| `git: command not found` или «git не является внутренней командой» | Поставить git. На Windows после этого перезапустить Терминал |
| Установщик закрылся с ошибкой на шаге 1/4 | Нет доступа к astral.sh: пропал интернет, мешает корпоративный прокси или антивирус. Проверьте сеть и запустите снова |
| «Не удалось скачать модели» | Оборвалась сеть. Запустите установщик ещё раз, скачанное сохранится |
| macOS пишет, что не удаётся проверить разработчика | Запускать `bash install.sh` в Терминале, двойной щелчок не подходит |
| «Система Windows защитила ваш компьютер» | «Подробнее», затем «Выполнить в любом случае». Чтобы окно не появлялось, разблокируйте архив (шаг 2 для ZIP) |
| Самопроверка не прошла на видеокарте NVIDIA | Установщик сам переключит распознавание на процессор. Если этого не произошло, выполните `.\install.bat -Cpu` и обновите драйвер NVIDIA до версии 525 или новее |
| Мало места на диске | Нужно около 6 ГБ, с CUDA около 8 ГБ. Можно ставить только быструю модель: `--model large-v3-turbo` |
| Браузер не открылся или пишет, что страница недоступна | Приложение ещё запускается. Подождите 5-10 секунд и обновите http://127.0.0.1:8770 |
| Порт 8770 занят другой программой | Создать в папке приложения файл `settings.env` со строкой `TRANSKRIBATOR_PORT=8780` |
| «Обновления» пишет, что приложение установлено не через git | Это установка из ZIP, смотрите [переход с ZIP на git](#переход-с-zip-на-git) |
| «Слушать» пишет, что звук не поступает (Mac) | Проверить, что на компьютере что-то играет, и разрешить «Транскрибатор Звук» в Системных настройках: Конфиденциальность и безопасность > Запись экрана и системного звука |
| «Слушать» пишет, что звук не поступает (Windows) | Звук должен идти на устройство вывода по умолчанию (Параметры > Система > Звук). Если сменили наушники или колонки, начните запись заново |
| «Слушать» недоступно на Mac | Нужна macOS 14.2 или новее |
| Расшифровка идёт очень медленно | Без видеокарты лучше выбирать быструю модель, подробнее в [REQUIREMENTS.md](REQUIREMENTS.md) |
