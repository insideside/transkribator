## Перед началом

**1. Выберите способ.**

| | Через git | Через ZIP |
|---|---|---|
| Обновление | кнопкой **«Обновления»** в приложении | вручную: скачать новый архив |
| Нужно заранее | программа git | ничего |
| Сложность | несколько команд в терминале | скачать, распаковать, дважды щёлкнуть (Windows) / одна команда (macOS) |

Если сомневаетесь — берите git: один раз поставили, дальше обновления приходят кнопкой.

**2. Выберите место для папки.** Приложение запускается прямо из своей папки, в ней же хранятся модели (≈3–5 ГБ),
история и загруженные записи. Поэтому:

- ✅ **macOS:** домашняя папка — `/Users/<имя>/transkribator` (в Finder: **Переход → Домой**, ⇧⌘H).
- ✅ **Windows:** `C:\Users\<имя>\transkribator`.
- ❌ **Не кладите** папку в **«Документы» или на «Рабочий стол», если они синхронизируются** с iCloud Drive (macOS)
  или OneDrive (Windows часто включает это по умолчанию): туда начнут выгружаться гигабайты моделей и ваши записи.
- ❌ Не запускайте приложение из «Загрузок», внешнего диска или флешки — только из постоянного места.

**3. Нужен интернет** — только на время установки (скачивается ≈2–5 ГБ). Потом приложение работает без сети.

## Способ 1. Через git (рекомендуется)

### macOS (git)

1. Откройте **Терминал**: Spotlight (⌘ Пробел) → «Терминал», или **Программы → Утилиты → Терминал**.
2. Перейдите в домашнюю папку и скачайте приложение:
   ```bash
   cd ~
   git clone https://github.com/insideside/transkribator.git
   ```
   Если git ещё не установлен, macOS покажет окно **«Для команды git нужны инструменты разработчика»** →
   нажмите **«Установить»**, дождитесь окончания (несколько минут) и выполните `git clone …` ещё раз.
3. Запустите установщик:
   ```bash
   cd ~/transkribator
   bash install.sh
   ```
4. Дождитесь надписи **«Готово!»** (5–20 минут, в основном — скачивание моделей). Установщик может спросить,
   поставить ли виджет на рабочий стол, — это вопрос только при установленном [Übersicht](https://tracesof.net/uebersicht/).
5. Готово — см. [Первый запуск](#первый-запуск).

### Windows (git)

1. **Установите git**, если его нет. Проще всего — откройте **Терминал**: правый клик по «Пуску» → **Терминал**
   (в Windows 10 этот пункт называется **Windows PowerShell**) — и выполните:
   ```powershell
   winget install --id Git.Git -e
   ```
   Или скачайте установщик с [git-scm.com/download/win](https://git-scm.com/download/win) и пройдите его
   со всеми настройками по умолчанию.
   **После установки git закройте и заново откройте Терминал** — иначе команда `git` не найдётся.
2. В Терминале перейдите в свою папку и скачайте приложение:
   ```powershell
   cd ~
   git clone https://github.com/insideside/transkribator.git
   ```
3. Запустите установщик:
   ```powershell
   cd transkribator
   .\install.bat
   ```
   (Можно и мышкой: откройте папку `C:\Users\<имя>\transkribator` и дважды щёлкните `install.bat`.)
4. Дождитесь надписи **«Готово!»** и нажмите любую клавишу, чтобы закрыть окно.
5. Готово — см. [Первый запуск](#первый-запуск).

## Способ 2. Через ZIP-архив

Скачать архив: на странице [github.com/insideside/transkribator](https://github.com/insideside/transkribator)
зелёная кнопка **Code → Download ZIP**. Внутри — папка **`transkribator-main`**.

### macOS (ZIP)

1. Safari сам распакует архив в **«Загрузки»**: появится папка `transkribator-main`
   (если нет — дважды щёлкните `transkribator-main.zip`).
2. **Перенесите папку** `transkribator-main` в домашнюю папку (⇧⌘H в Finder).
   Можно переименовать её в `transkribator` — на работу это не влияет.
3. Откройте **Терминал** и выполните (замените имя папки, если переименовали):
   ```bash
   cd ~/transkribator-main
   bash install.sh
   ```
   Запускайте именно так, **не двойным щелчком** по `install.sh`: macOS не даёт открывать скрипты из интернета
   двойным щелчком («не удаётся проверить разработчика»). Установщик сам снимет эту метку с файлов приложения.
4. Дождитесь **«Готово!»** — см. [Первый запуск](#первый-запуск).

### Windows (ZIP)

1. Найдите скачанный `transkribator-main.zip` в **«Загрузках»**.
2. **Разблокируйте архив** — иначе Windows будет пугать предупреждениями при каждом запуске:
   правый клик по архиву → **Свойства** → внизу галочка **«Разблокировать»** → **ОК**.
   (Если такой галочки нет — всё в порядке, пропустите шаг.)
3. **Распакуйте**: правый клик по архиву → **«Извлечь все…»** → в поле пути укажите `C:\Users\<имя>` → **Извлечь**.
   Появится папка `C:\Users\<имя>\transkribator-main`.
   ⚠️ Не запускайте ничего **изнутри архива**: Проводник открывает ZIP как обычную папку, но установка оттуда не сработает.
4. Откройте папку `transkribator-main` и дважды щёлкните **`install.bat`**.
   - Если появится синее окно **«Система Windows защитила ваш компьютер»**: **Подробнее → Выполнить в любом случае**.
5. Дождитесь **«Готово!»**, нажмите любую клавишу — см. [Первый запуск](#первый-запуск).

## Что делает установщик

Всё ставится **внутрь папки приложения** и в папку пользователя; права администратора не нужны, системный Python
и другие программы не затрагиваются.

| Шаг | Что происходит | Сколько |
|---|---|---|
| 1/4 | Ставит [uv](https://docs.astral.sh/uv/) — менеджер Python-окружения (в `~/.local/bin`) | секунды |
| 2/4 | uv скачивает Python 3.12 и библиотеки строго по списку версий (`uv.lock`); на Windows с NVIDIA — ещё библиотеки CUDA (≈1,3 ГБ) | 1–5 мин |
| 3/4 | Скачивает модели: разделение по голосам (≈80 МБ) и распознавание — точную (≈3 ГБ) при наличии видеокарты или быструю (≈1,6 ГБ) без неё | 1–15 мин |
| — | **Самопроверка**: ffmpeg, движок распознавания, модели, прогон тестового звука через весь конвейер | ≈30 с |
| 4/4 | Ярлык: macOS — **«Транскрибатор» в Программах**; Windows — на **рабочем столе** и в **«Пуске»** | секунды |

Успех выглядит так:
```
Проверка установки (движок: mlx, Python 3.12, darwin)
  ✓ ffmpeg — ffmpeg читает m4a
  ✓ Движок распознавания — MLX, Device(gpu, 0)
  ✓ Модели диаризации — есть
  ✓ Диаризация — sherpa-onnx загружает модели
  ✓ Весь конвейер — модель large-v3, конвейер отработал
Всё работает.
```
Если где-то ✗ — ниже [что делать](#если-что-то-пошло-не-так). Установщик можно спокойно запускать повторно:
уже скачанное не качается заново.

## Первый запуск

**macOS:** «Транскрибатор» в **Программах** (или Launchpad / Spotlight). Значок появится в Dock, пока приложение работает;
**правый клик по значку → Завершить** — остановить. Можно закрепить в Dock: правый клик → Параметры → Оставить в Dock.
Запасной способ — двойной щелчок по `start.command` в папке приложения.

**Windows:** ярлык **«Транскрибатор»** на рабочем столе или в «Пуске». На панели задач появится свёрнутое окно
**«Transkribator»** — это сервер приложения; **закройте его, чтобы остановить** приложение.
Запасной способ — `start.bat` в папке приложения.

В обоих случаях откроется браузер с адресом **http://127.0.0.1:8770**. Можно добавить его в закладки:
пока приложение запущено, адрес работает. Это страница на вашем компьютере, в интернет ничего не уходит.

## Параметры установщика

macOS: `bash install.sh <параметры>` · Windows (в Терминале из папки приложения): `.\install.bat <параметры>`

| macOS / Linux | Windows | Что делает |
|---|---|---|
| `--all-models` | `-AllModels` | скачать обе модели: точную (≈3 ГБ) и быструю (≈1,6 ГБ), чтобы выбирать при загрузке |
| `--model large-v3` | `-Model large-v3` | скачать конкретную модель (`large-v3` — точная, `large-v3-turbo` — быстрая) |
| — | `-Cpu` | не использовать видеокарту NVIDIA (если с ней проблемы) |
| `--no-shortcut` | `-NoShortcut` | не создавать ярлыки |
| `--no-widget` | — | не предлагать виджет Übersicht |

Докачать вторую модель позже — просто запустить установщик ещё раз с `--all-models` / `-AllModels`.

## Обновление

**Установлено через git:** кнопка **«Обновления»** в шапке приложения (точка на ней — есть новая версия).
В окне видно, что изменилось; **«Обновить»** — и приложение само скачает изменения, доустановит библиотеки
(если нужно) и перезапустится. Модели, история и записи не затрагиваются.
Вручную — в Терминале: `cd ~/transkribator && git pull`, затем установщик ещё раз.

**Установлено из ZIP:** скачайте новый архив и распакуйте его **поверх** старой папки
(Windows: «Извлечь все…» в ту же `C:\Users\<имя>` → на вопрос о замене файлов — **Заменить**;
macOS: скопируйте содержимое новой `transkribator-main` в старую с заменой). Затем запустите установщик ещё раз —
он доустановит изменения, модели и история останутся. Удобнее — [перейти на git](#переход-с-zip-на-git).

## Переход с ZIP на git

Чтобы включить обновления кнопкой, не скачивая модели заново:

1. Установите git (см. [macOS](#macos-git) / [Windows](#windows-git), шаг про git) и выполните `git clone …` в домашней папке —
   появится новая папка `transkribator`.
2. **Перенесите** из старой папки (`transkribator-main`) в новую папки **`models`** и **`data`**
   (и файл `settings.env`, если он есть). Так сохранятся модели, история и записи.
3. Запустите установщик в новой папке — он займёт минуту: модели уже на месте. Ярлыки перенастроятся на новую папку.
4. Старую папку `transkribator-main` удалите.

## Удаление

1. Запустите `uninstall.sh` (macOS: `bash ~/transkribator/uninstall.sh`) или `uninstall.bat` (Windows) —
   они удалят ярлыки, приложение из «Программ» и виджет.
2. Удалите папку приложения — вместе с ней уйдут модели, история и загруженные записи.
3. Необязательно: удалить менеджер uv и его кэш (если он не нужен другим программам):
   - macOS: `uv cache clean && rm -rf "$(uv python dir)" && rm ~/.local/bin/uv ~/.local/bin/uvx`
   - Windows (Терминал): `uv cache clean; Remove-Item -Recurse -Force "$(uv python dir)"; Remove-Item $HOME\.local\bin\uv.exe, $HOME\.local\bin\uvx.exe, $HOME\.local\bin\uvw.exe`

Больше приложение ничего в системе не оставляет.

## Если что-то пошло не так

Сначала — **самопроверка** в папке приложения:
macOS `.venv/bin/python -m app.selftest` · Windows `.venv\Scripts\python.exe -m app.selftest`.
Подробности любых ошибок — в **`data/logs/app.log`**.

| Что видите | Что сделать |
|---|---|
| `git: command not found` / «git не является внутренней командой» | Установите git (см. выше); на Windows после установки **перезапустите Терминал** |
| Окно установщика закрылось с ошибкой на шаге 1/4 | Нет доступа к astral.sh (интернет, корпоративный прокси, антивирус). Проверьте сеть и запустите снова |
| «Не удалось скачать модели» | Обрыв сети — запустите установщик ещё раз, скачанное сохранится |
| macOS: «не удаётся проверить разработчика» | Запускайте `bash install.sh` в Терминале, а не двойным щелчком |
| Windows: «Система Windows защитила ваш компьютер» | **Подробнее → Выполнить в любом случае**; чтобы не повторялось — разблокируйте архив (шаг 2 для ZIP) |
| Самопроверка: ✗ с видеокартой NVIDIA | Установщик сам переключит на процессор; если нет — `.\install.bat -Cpu`. Обновите драйвер NVIDIA (нужен 525+) |
| Мало места на диске | Нужно ≈6 ГБ (≈8 ГБ с CUDA). Можно ставить только быструю модель: `--model large-v3-turbo` |
| Браузер не открылся / «не удаётся получить доступ» | Приложение ещё запускается — подождите 5–10 с и обновите страницу http://127.0.0.1:8770 |
| Порт 8770 занят другой программой | Создайте в папке приложения файл `settings.env` со строкой `TRANSKRIBATOR_PORT=8780` |
| Кнопка «Обновления»: «установлено не через git» | Это ZIP-установка — см. [Переход с ZIP на git](#переход-с-zip-на-git) |
| Расшифровка очень медленная | Без видеокарты используйте быструю модель; подробнее — [технические требования](REQUIREMENTS.md) |
