# Технические требования

Что нужно компьютеру, чтобы Транскрибатор работал, и чего ждать по скорости.
Установка — в [INSTALL.md](INSTALL.md).

> **Как получены цифры.** Отмечено **(замер)** — измерено на MacBook Pro M4 Pro (14 ядер CPU, 20 ядер GPU, 48 ГБ)
> на записи 20 и 63 минуты с тремя говорящими. **(оценка)** — пересчитано из этих замеров, официальных тестов
> [faster-whisper](https://github.com/SYSTRAN/faster-whisper#benchmark) и сравнения многоядерной производительности процессоров.
> Оценки дают порядок величин: реальная скорость зависит от охлаждения ноутбука, фоновых программ и самой записи.

## Коротко

| | Минимум | Рекомендуется |
|---|---|---|
| **Mac** | Apple Silicon (M1 и новее), **macOS 14 Sonoma+**, 8 ГБ памяти (быстрая модель) | M1 Pro/M2 и новее, **16 ГБ** |
| **Windows** | Windows 10/11 **64-бит (x64)**, 4+ ядра, **8 ГБ** памяти (быстрая модель) | видеокарта **NVIDIA с 6+ ГБ видеопамяти** (драйвер 525+), 16 ГБ памяти |
| **Linux** | x86-64, 8 ГБ памяти | видеокарта NVIDIA |
| **Диск** | ≈3 ГБ (быстрая модель) | ≈6–8 ГБ (обе модели, CUDA) + место под записи |
| **Сеть** | только во время установки и обновлений | |
| **Браузер** | Chrome/Edge 111+, Safari 16.2+, Firefox 113+ | |

## Какая модель подходит вашему компьютеру

| Модель | Качество | Размер | Когда выбирать |
|---|---|---|---|
| **Точная** (Whisper large-v3) | лучшее: ошибок в словах ≈2,4 % (замер на синтетической чистой речи; на живых записях с шумом — больше) | 3,1 ГБ | Mac с Apple Silicon и ПК с NVIDIA — по умолчанию |
| **Быстрая** (Whisper large-v3 turbo) | чуть ниже: ≈4,0 % (замер) | 1,6 ГБ | компьютер без видеокарты — по умолчанию; Mac с 8 ГБ памяти |

Установщик выбирает сам: есть видеокарта (Apple Silicon или NVIDIA) — точная, нет — быстрая.
Вторую модель можно докачать: `install.sh --all-models` / `install.bat -AllModels`.

## Скорость: сколько расшифровывается час записи

Разделение по голосам всегда считается на процессоре, параллельно с распознаванием. Поэтому на мощной видеокарте
общее время часто ограничено именно им, а не моделью.

### Mac (Apple Silicon, распознавание на видеочипе)

| Компьютер | Точная | Быстрая |
|---|---|---|
| M4 Pro / M3 Pro / M2 Max и выше | **≈8–9 мин** (замер: 63 мин за 8,6 мин) | ≈6–8 мин (по замеру на 20 мин: 2 мин 6 с; упирается в разделение голосов) |
| M1 / M2 / M3 базовые (8 ядер GPU) | ≈15–25 мин (оценка) | ≈12–18 мин (оценка) |
| Intel Mac | не рекомендуется: только процессор, см. «Без видеокарты»; не проверялось | |

### Windows / Linux с видеокартой NVIDIA

| Видеокарта | Режим | Час записи (оценка) |
|---|---|---|
| RTX 3060 / 4060 и выше (6+ ГБ) | float16, точная | ≈8–12 мин — упирается в разделение голосов на процессоре |
| GTX 1650 / 1660, RTX 3050 (4 ГБ) | int8 (включается автоматически), точная | ≈15–20 мин |
| GTX 10xx | int8 (автоматически) | ≈20–30 мин |

Основа оценки: по официальному тесту faster-whisper модель large на RTX 3070 Ti расшифровывает 13 минут аудио примерно за минуту,
а разделение по голосам на 8-ядерном процессоре занимает ≈8–10 минут на час записи.

### Без видеокарты (только процессор)

| Процессор | Быстрая | Точная |
|---|---|---|
| Apple M4 Pro, 14 ядер (для сравнения) | ≈12 мин (по замеру на 20 мин: 4 мин 4 с) | ≈40–45 мин (оценка) |
| Мощный настольный: Ryzen 7/9, Core i7/i9 последних поколений | ≈15–20 мин | ≈1 ч |
| Обычный ноутбук: Core i5 / Ryzen 5, 4–6 ядер | ≈25–40 мин | ≈1,5–2,5 ч |
| Старый 4-ядерный (до ~2018 г.) | ≈1–1,5 ч | не рекомендуется (3+ ч) |

Точная модель на процессоре в 3–4 раза медленнее быстрой (у неё в 8 раз больше слоёв декодера).
Без видеокарты почти всегда стоит брать быструю модель.

## Память (ОЗУ)

Расход почти не зависит от длины записи: длинные записи обрабатываются частями.

| Конфигурация | Пик во время расшифровки | Сколько нужно |
|---|---|---|
| Mac, точная | ≈5,7 ГБ (замер: 4,4 ГБ распознавание + 1,3 ГБ разделение голосов) | **16 ГБ** |
| Mac, быстрая | ≈3,6 ГБ (замер: 2,3 + 1,3) | 8 ГБ — впритык, лучше 16 |
| Процессор, быстрая | ≈4,9 ГБ (замер: 3,6 + 1,3) | 8 ГБ |
| Процессор, точная | ≈5,7 ГБ (оценка) | 16 ГБ |
| NVIDIA, точная | ≈3 ГБ ОЗУ + **видеопамять ≈4,5 ГБ** (float16) или **≈3 ГБ** (int8, карты с памятью < 6 ГБ) | 8 ГБ ОЗУ, 4+ ГБ видеопамяти |

Каждый час записи добавляет ≈0,5 ГБ (звук целиком держится в памяти для перемотки и разрезов).
Чтобы расшифровка шла без рывков, закройте тяжёлые программы — особенно на компьютерах с 8 ГБ.

## Процессор

- **Mac:** Apple Silicon (M1 и новее). Intel Mac запустится, но только на процессоре и медленно (не проверялось).
- **Windows / Linux:** 64-битный x86-64 (Intel/AMD). Минимум 4 ядра, лучше 6–8.
- **Не поддерживается:** Windows на ARM (Snapdragon, Surface Pro X) — для этой платформы нет нужных библиотек;
  32-битная Windows.
- Видеокарты **AMD и Intel** не используются: распознавание пойдёт на процессоре.

## Видеокарта

- **Apple Silicon** — используется всегда, ничего настраивать не нужно.
- **NVIDIA** — используется автоматически, если установщик нашёл драйвер (`nvidia-smi`):
  - нужен драйвер с поддержкой **CUDA 12** (версия **525** или новее); библиотеки CUDA/cuDNN установщик ставит сам (≈1,3 ГБ);
  - при видеопамяти меньше 6 ГБ приложение само включает экономный режим int8;
  - если с видеокартой что-то не так, приложение само переходит на процессор.
    Принудительно: `install.bat -Cpu` или строка `TRANSKRIBATOR_DEVICE=cpu` в файле `settings.env`.
- Работа на видеокартах NVIDIA на реальном железе **пока не проверялась** (автотесты GitHub идут без видеокарты).
  Если что-то не так — пришлите `data/logs/app.log` в Issues.

## Место на диске

| Что | Размер |
|---|---|
| Точная модель | 3,1 ГБ |
| Быстрая модель | 1,6 ГБ |
| Разделение по голосам | 0,09 ГБ |
| Python и библиотеки | ≈1,3 ГБ (замер, Mac) |
| Библиотеки CUDA (только NVIDIA) | ≈2,5 ГБ (оценка, в распакованном виде) |
| Ваши записи | копия каждого загруженного файла хранится в `data/uploads/` (для плеера и повторной обработки) |

Итого: Mac ≈4,5 ГБ (одна модель) или ≈6 ГБ (обе); Windows без видеокарты ≈3 ГБ; Windows с NVIDIA ≈7 ГБ.
